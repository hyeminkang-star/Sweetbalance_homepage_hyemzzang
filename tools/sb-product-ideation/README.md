# 신제품 아이디어 발굴 프로그램

리뷰 크롤링 파일·매출·트렌드 데이터를 근거로 신제품 콘셉트 후보를 뽑아 **엑셀 + 요약 보고서**로 저장하는 프로그램입니다.
PC 폴더에 저장한 파일과 **구글 시트/드라이브 링크**를 둘 다 불러올 수 있습니다.

> 점수와 순위는 AI 참고 의견입니다. 최종 선택은 상품팀이 합니다.

## 처음 한 번 준비

1. **파이썬 설치**: https://www.python.org/downloads/ (윈도우는 설치 화면에서 "Add python.exe to PATH" 체크)
2. **Claude API 키 발급**: https://console.anthropic.com → API Keys → Create Key (`sk-ant-...`). API 사용량만큼 요금이 나갑니다.
3. 이 폴더(`sb-product-ideation`)를 PC에 내려받습니다.

## 실행

- 윈도우: `실행_윈도우.bat` 더블클릭
- 맥: `실행_맥.command` 더블클릭 (처음에 "확인되지 않은 개발자" 경고가 뜨면 우클릭 → 열기)

처음 실행할 때는 필요한 프로그램을 설치하느라 몇 분 걸립니다. 그다음 브라우저에 화면이 열립니다.

1. 왼쪽 **설정**에 API 키를 넣습니다("이 PC에 키 저장"을 켜면 다음부터 자동 입력).
2. **PC 데이터 폴더 경로**를 넣거나, **구글 링크**를 종류별 칸에 한 줄에 하나씩 붙여 넣습니다(둘 다 가능).
3. **신제품 아이디어 뽑기**를 누릅니다. 몇 분 뒤 화면에서 엑셀과 보고서를 내려받을 수 있고, `결과/날짜_시간/` 폴더에도 저장됩니다.

## 데이터 넣는 법

### PC 폴더

```
내데이터/
  리뷰/      리뷰 크롤링 .xlsx/.csv (여러 개 가능)
  매출/      제품별 매출·목표(·달성률)
  트렌드/    키워드, 검색량, 증감률, 출처 (선택)
  제품마스터.xlsx  제품명, 재료, 가격, kcal, 카테고리, 별칭 (선택)
```

하위 폴더 대신 파일 이름에 `리뷰`, `매출`, `트렌드`, `마스터`를 넣어도 됩니다.

### 구글 링크

- 구글 시트 링크(`docs.google.com/spreadsheets/...`)와 드라이브에 올린 엑셀/CSV 파일 링크(`drive.google.com/file/...`)를 지원합니다.
- 파일의 **[공유] → 일반 액세스 → "링크가 있는 모든 사용자(뷰어)"** 로 설정해야 불러올 수 있습니다. 로그인 없이 받기 때문입니다.
- 드라이브 **폴더** 링크는 지원하지 않습니다. 파일 링크를 하나씩 넣어 주세요.
- 외부 공유를 할 수 없는 파일은 엑셀로 내려받아 PC 폴더에 넣어 주세요.

`examples/sample_data/`에 형식 예시가 있습니다. **예시 파일 내용은 테스트용으로 지어낸 가짜 데이터**입니다.

## 결과물

- `신제품_콘셉트후보_날짜.xlsx`: 읽어주세요 / 콘셉트 후보(상품팀 검토 칸) / 근거 리뷰 / 제품별 현황 / 속성 분석 / 트렌드
  - 근거 리뷰는 원문 그대로, 파일명·행 번호와 함께 적힙니다.
  - AI가 데이터에 없는 리뷰 번호를 댄 후보는 빨간색 "근거 확인 필요"로 표시됩니다.
- `요약보고서_날짜.md`: 팀장님 공유용 요약(추천 TOP 5, 근거, 리스크, 트렌드 출처)
- `analysis.json`, `concepts.json`: 분석 원자료

## 처리 순서

1. 데이터 분석(프로그램): 파일 자동 인식, 제품별 평점·달성률, 속성별(맛·식감·양·가격 등) 긍정/부정, 바라는 점·불만 리뷰 추출
2. 트렌드(선택): 트렌드 파일이 없으면 Claude가 웹 검색으로 키워드를 찾습니다. 실제 검색 결과에 나온 URL을 출처로 단 것만 남깁니다.
3. 콘셉트 생성(Claude): 리뷰 번호를 근거로 단 후보를 만들고 5개 항목으로 점수를 매깁니다.
4. 엑셀·보고서 저장(프로그램): 근거 리뷰 번호를 실제 데이터와 대조합니다.

## 비용

API 요금은 리뷰 양과 모델에 따라 달라집니다. 실행 기록에 호출마다 입력/출력 토큰 수가 표시되니, 처음에는 리뷰 수나 콘셉트 개수를 줄여서 비용을 확인해 보세요.
요금표: https://www.anthropic.com/pricing#api

## 명령어로 실행 (선택)

```bash
pip install -r requirements.txt
python run.py --folder "내데이터"
python run.py --review-link "https://docs.google.com/spreadsheets/d/..." --sales-link "https://..." --n 30
```

## 바꿀 수 있는 곳

- 컬럼명 인식: `ideation/analyze.py`의 `COLUMN_ALIASES` (크롤링 파일 컬럼명이 다르면 여기에 추가)
- 맛·식감 등 속성 단어: `ideation/analyze.py`의 `ATTRIBUTES`
- 점수 가중치: `ideation/excel.py`의 `WEIGHTS`
- AI 지시문: `ideation/ai.py`의 `SYSTEM_PROMPT`
