TO-BE

스윗밸런스 디자인 시스템을 따르는 실제 자사몰 홈페이지. 첫 화면, 신제품 소개, 오늘의 샐러드, 점심 메뉴 룰렛, 브랜드 소개까지 5개 섹션과 실제 작동하는 인터랙션을 포함.

01화면 구성

1
헤더워드마크 로고, 신제품·오늘의 샐러드·점심 메뉴 뽑기·브랜드 소개 내비게이션, 상품 문의 아이콘 버튼.
2
첫 화면 (Hero)"이 정도면, 나도 할 수 있겠다." 안심형 헤드라인 + 저당·고단백·식이섬유 배지 + 통계(평균 단백질/칼로리/식이섬유).
3
신제품 소개통밀 프로틴 랩 4종을 실제 가격·할인가·품절 상태 그대로 카드로 소개. 마켓컬리 입점 안내 포함.
4
오늘의 샐러드요일 칩을 누르면 그날의 샐러드로 바뀌는 주간 로테이션. 접속 요일을 자동 인식해 오늘 메뉴를 기본 표시.
★
점심 메뉴 고민 해결 버튼주인공 기능필터를 고르고 버튼을 누르면 메뉴가 룰렛처럼 돌다가 하나로 착지 — 실제로 작동하는 인터랙션. 아래 02번에서 상세 설명.
5
샐러드 이름 타자 게임60초 동안 실제 샐러드·신제품 이름이 랜덤으로 출제되는 한컴타자 스타일 미니게임. 타/분·정확도·맞춘 개수를 실시간으로 보여줍니다.
6
브랜드 소개워드마크 로고, 미션 선언문, 슬로건, Warm·Fresh·Honest 브랜드 성격, 푸터.

02주인공 기능 — 점심 메뉴 고민 해결 버튼

"오늘 점심 뭐 먹지"라는 매일의 고민을 스윗밸런스가 대신 해결해주는 기능입니다. 실제 스윗밸런스 샐러드 라인업과 신제품 통밀 프로틴 랩을 포함한 메뉴 풀에서, 사용자가 고른 스타일에 맞춰 결과를 골라줍니다.

STEP 1
스타일 선택가볍게 / 든든하게 / 저당 / 고단백 중 원하는 무드를 고릅니다.
STEP 2
뽑기 버튼 클릭메뉴 이름이 빠르게 돌아가며 룰렛처럼 연출됩니다.
STEP 3
결과 카드 등장이모지·칼로리·단백질·식이섬유·태그가 담긴 카드가 스프링 애니메이션으로 나타납니다.
STEP 4
결정 또는 재도전"다시 뽑기"로 재도전하거나 "좋아요, 이걸로 할래요!"로 확정하면 응원 토스트가 뜹니다.

03인터뷰 답변이 반영된 곳

질문답변반영 위치
1. 타겟 고객운동 / 다이어터헤드라인, 배지, 통계 수치, 메뉴 태그(고단백·저당)가 모두 운동·다이어트 목표에 맞춰 설계됨
2. 첫인상 문장"이 정도면 나도 할 수 있겠다" 안심Hero 헤드라인 "이 정도면, 나도 할 수 있겠다."로 그대로 문구화
3. 대표 제품오늘의 샐러드요일별로 바뀌는 "오늘의 샐러드" 전용 섹션으로 구성
4. 핵심 아이디어 기능점심 메뉴 고민 해결 버튼페이지의 주인공 기능으로 가장 공들여 제작 (02번 참고)
5. 분위기미니멀 화이트Sunshine White 배경 위 넉넉한 여백, Seed Green 한 가지만 포인트로 절제 사용
